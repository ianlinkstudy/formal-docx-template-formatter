# 富对象与核验

## 语义完整性

核验同时比较：

- 段落文字与顺序；
- 顶层、合并和嵌套表格结构；
- 页眉页脚段落与表格；
- 行内图片和媒体部件哈希；
- OMML 公式 XML 哈希；
- Equation/MathType OLE 对象和嵌入部件哈希。

公式或图片内容变化必须使核验失败。允许变化的只有声明的排版属性、表格列宽和超宽行内图片尺寸。

## 图片

- 只处理正文顶层行内图片。
- 超过当前版心宽度时等比缩小并居中。
- 不裁剪、不旋转、不重编码图片，不修改图片部件。
- 浮动对象、页眉页脚图片和表格内图片保持原位并在报告中提示。
- 只识别已有“图1”等题注，不自动新增题注。

## 表格

- 支持合并单元格、边框、列宽、单元格留白和跨页重复表头。
- 不改变行列数、合并关系或单元格文字。
- 嵌套表保留原样并明确提示，不在未核验时声称已自动排版。

## 公式与母版

- 行内 OMML 随正文段落排版，公式节点本身保持不变。
- 独立公式应用模板规则；没有可靠规则时保留已有对齐和编号，不自动新增编号。
- 母版模式首版只接受单节输入正文。
- 母版合并后必须验证源正文全部出现、源图片/公式哈希存在，以及模板页眉页脚结构未变化。
