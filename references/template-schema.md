# 模板配置与锚点

## Profile

有效配置保存在用户目录的 `TEMPLATES/ID/profile.json`，主要字段：

- `page`：纸张、页边距和页面策略。
- `styles`：`title`、`recipient`、`metadata`、`heading1` 至 `heading4`、`body`、`body_item`、表格/图片题注、`signature`、`date`、`formula_display`。
- 每个样式规则可配置中文字体、西文字体、字号、粗体、斜体、颜色、对齐、行距、段前段后、首行/右缩进和 `keep_with_next`。
- `table`：表头/正文样式、边框、对齐、跨页重复表头、留白和适宽策略。
- `figure`：内嵌图片最大宽度比例与对齐。
- `formula`：公式和 OLE 对象哈希策略。

修改只使用 `amend`，不要直接编辑正式模板目录中的 JSON。

## 母版锚点

规范锚点：

- `{{TITLE}}` / `{{标题}}`
- `{{RECIPIENT}}` / `{{主送机关}}`
- `{{BODY}}` / `{{正文}}`
- `{{SIGNATURE}}` / `{{落款}}`
- `{{DATE}}` / `{{日期}}`

`BODY` 必须存在且唯一；其余锚点可选、最多一次。未知、重复或缺失正文锚点会阻止确认。

如果母版没有锚点，可在摘要的 `blocks` 中选择连续正文样例范围，通过 `amend --body-start N --body-end M` 生成 `{{BODY}}`。源模板文件保持不变，用户确认后只把派生母版存入本地模板库。

## 内容映射

- 有专用锚点时，对应标题、主送机关、落款和日期分别迁入。
- `BODY` 接收其余全部段落、表格、图片、编号和公式，保持源顺序。
- 专用锚点不存在时，对应内容仍随 `BODY` 迁入，避免丢内容。
- 母版固定封面、目录、页眉页脚、页码和模板文案保持不变。
