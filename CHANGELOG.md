# Changelog

## 1.0.0 - 2026-10-27

- Published the first standalone release of `formal-docx-template-formatter`.
- Added explicit template selection before every formatting task.
- Added the built-in `GB/T 9704-2012 参考版` profile.
- Added a local library for up to three confirmed custom templates.
- Added DOCX/DOTX inspection, amendment, hash-bound confirmation, naming, archive, restore, and rename operations.
- Added style-template extraction and shell-template processing with `{{TITLE}}`, `{{RECIPIENT}}`, `{{BODY}}`, `{{SIGNATURE}}`, and `{{DATE}}` anchors.
- Added semantic integrity checks for paragraphs, merged and nested tables, headers and footers, media parts, OMML formulas, and OLE objects.
- Added independent page, typography, indent, and table verification.
- Added a font-aware PDF/PNG preview helper.
- Added automated lifecycle, formatting, CLI, and rich-object tests.
- Added fictional examples, release materials, security guidance, and a GitHub Actions test workflow.
