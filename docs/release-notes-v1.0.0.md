# Word 模板排版 1.0.0

发布日期：2026-10-27

## 本次发布

这是 `formal-docx-template-formatter` 的首个独立公开版本。

它解决的不只是“按公司模板把字排一下”，而是两个容易被省略的控制点：

1. 单位模板必须先解析、展示、确认、命名，才允许保存；
2. 每次排版必须先选定模板，并在输出后独立核验内容和结构。

## 模板能力

- 内置 `GB/T 9704-2012 参考版`；
- 最多 3 套有效自定义 DOCX/DOTX 模板；
- 支持样式模式与母版模式；
- 支持标题、主送机关、正文、落款和日期锚点；
- 支持归档、恢复和重命名；
- 候选确认与 `candidate_sha256` 绑定。

## 完整性能力

- 段落文字和顺序；
- 合并及嵌套表格；
- 页眉页脚；
- 行内图片和媒体部件；
- OMML 公式；
- OLE 对象和嵌入部件；
- 页面、字体、字号、行距、对齐、缩进与表格样式。

## 验证

- 自动测试覆盖模板状态机、CLI、样式排版、母版合并、表格、图片、公式和篡改检测；
- 虚构示例生成新 DOCX、排版报告和核验报告；
- 压缩包通过内容清单与 SHA-256 完整性检查。

## 安装

```bash
npx skills add ianlinkstudy/formal-docx-template-formatter
```

需要 Python 3.10 或更高版本。
