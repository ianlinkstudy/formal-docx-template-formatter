# 迭代记录

## 1.0.0 - 2026-10-27

首个独立公开版本。

### 模板优先

- 每次排版任务先列出内置模板和已保存自定义模板；
- GB/T 9704-2012 参考版不占自定义槽位；
- 自定义模板最多保留 3 套有效版本，另设归档区。

### 确认状态机

- 候选模板必须经过解析、摘要展示、用户明确确认、命名和保存；
- 确认与候选哈希绑定；
- 修改、未确认、未命名或保存失败时都不能进入模板选择列表；
- 母版锚点未知、重复或缺少 `{{BODY}}` 时阻止确认。

### 排版与核验

- 样式模式提取页面、角色、字体、字号、行距、缩进和表格规则；
- 母版模式保留固定封面、模板文案和页眉页脚，并迁移源正文；
- 保存前比较正文、表格、页眉页脚、图片、OMML 公式和 OLE 对象；
- 独立核验页面、字体、行距、对齐、缩进和表格样式。

### 发布

- 增加中文 README、使用手册、安全说明、贡献指南和发布说明；
- 增加 GitHub Actions 双版本 Python 测试；
- 增加虚构的源文档、样式模板、母版模板、输出和核验报告；
- 发布 ZIP、`.skill`、使用手册 PDF 与 SHA-256。

### 明确边界

- 首版只接受 `.docx`/`.dotx` 模板和单节输入正文；
- `.docm`、`.doc`、PDF 与扫描件先转换；
- 不自动重排浮动对象；
- 不声称通过脚本即达到法定公文合规。
